# Web Application Security Labs

Hands-on web application security labs from the course *Sécurité des applications et des services* (IT Security engineering cycle, FST Guéliz). Each lab follows the same method: **exploit in an authorised lab → explain the root cause → propose a server-side fix → define validation and regression tests.**

| Lab | Topic | Tools |
|---|---|---|
| [Lab 3](tp3-broken-access-control/) | Broken access control: IDOR (horizontal) and unprotected admin panel (vertical) | Burp Suite, PortSwigger Web Security Academy |
| [Lab 4](tp4-file-upload-xss-lfi-command-injection/) | Unrestricted file upload, reflected & stored XSS, LFI, OS command injection *(joint lab with Ikram Ezziouani)* | Kali Linux, Metasploit, msfvenom, DVWA / Metasploitable 2 |

More labs will be added.

> ⚠️ All exploitation was performed only in intentionally vulnerable, authorised lab environments. Never test these techniques on systems you are not allowed to test.

**Author:** Hiba El Hjouji — Cybersecurity engineering student, FST Guéliz (Université Cadi Ayyad).
